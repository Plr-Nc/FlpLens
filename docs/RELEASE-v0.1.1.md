# v0.1.1

## 新增

**体检页** —— 只读状态下的三项分析，FL Studio 本身做不到或做起来很麻烦。

- **轨道状态快照**：导出每个通道的音量、声像、插件、采样为 JSON 或 Markdown。纯文本、可进 git、可跨工程比对
- **工程对比**：直接选两个 `.flp`，只列出真正变化的字段 —— 通道增删、音量、BPM、音符数
- **依赖体检**：插件与设备清单、采样清单，以及空样式、闲置通道、重复加载的采样

明细直接在页面表格里查看，不需要先导出文件。各区块可折叠，默认状态下整页一屏放得下。

**界面**

- 设计令牌重构：四层背景、四级文字、发丝线
- 标签栏从实心按钮改为面板页签
- 列表密度收紧（样式 22px、通道 24px）
- 编排区空白加时间网格，剪辑降饱和
- 动效：滚动条自动隐藏、选中指示条展开、分隔条三档亮度、概览框拖拽抬升、面板淡入
- 缩放缓动改为阻尼跟随（90% 行程 96ms），大工程自动关闭以保证 60fps

**协作**

- Issue 表单（打不开 / 功能建议）与 PR 模板
- 提交前自动检查清单

## 修复

- **样式列表出现两条同索引记录、点一个亮两个** —— FL 对已删除的 pattern 槽位会重复写 `NEW_PATTERN`（74 个 pattern 写了 135 次），解析器无条件追加
- **插件清单大量缺失** —— 只统计了能读到名称的插件记录。同一工程从 9 种 / 12 通道修正为 14 类 / 58 通道
- **钢琴卷帘键名列被音符盖住** —— `z-index` 只在同一层叠上下文内比较，整行被压在下层
- **控制条遮住钢琴卷帘和控制区底部** —— 滚动区延伸到控制条下面，最后几行滚不出来
- **滚轮在时间轴两端失效** —— 无法保持锚点时拒绝整步缩放
- **滚轮在右上角手柄上无效**
- **概览框窄于 30px 时无法缩放**
- **列表 hover 与选中同色**，看起来像多项同时被选中
- **MIDI 导出面板遮住键名列**

## 说明

- 仍为**只读**工具，不写回、不修改 `.flp`，不做格式转换
- 部分插件记录在 FLP 里没有可读名称，这类通道按通道名归组并标注「名称未读到」，不会假装识别成功
